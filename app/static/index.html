浏览器登录

点一下跳转 MiniMax 登录页，登录完成后账号自动进池子，不用去 devtools 抄 _token。

无头注册 （海外版）

全程无浏览器：自动申请临时邮箱 → 收验证码 → 注册 → 用会话直接批准设备码 → 拿 OAuth token 入池。 仅支持海外版（account.minimax.io）。

代理池

注册按出口地址被风控计数，池子让每个号从不同地址出去。地址上限在「设置」的 signup.per_ip_limit；不填代理则直连（同一地址，易触发风控）。

代理协议出口 IP归属延迟已注册状态操作

手动导入 JWT

探测会读取 realUserID 与 agent 列表，逐个账号约需 1-3 秒。
目前只导入国际站（agent.minimax.io）；若本机不在海外，先在「设置」里填好 proxy，否则探测一定 401。

邮箱密码导入 （批量）

每行一个：邮箱 密码，也支持 邮箱----密码。导入时会用邮箱密码登录， 自动拿到 token 与 refresh_token 并入池——这类账号可以随时从控制台重新登录，不依赖浏览器。
